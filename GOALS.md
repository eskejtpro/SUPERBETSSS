# Cel

Prywatny, lokalny program Windows pokazujący wszystkie bieżące mecze e-piłki nożnej live oraz ich stan: liga, zawodnicy, wynik, połowa, czas, format, status i zmiany. Lista ma priorytetyzować spotkania o najkrótszym przewidywanym czasie do końca.

Poza zakresem: składanie zakładów, kupony, automatyzacja działań finansowych, odczyt salda i danych konta.
